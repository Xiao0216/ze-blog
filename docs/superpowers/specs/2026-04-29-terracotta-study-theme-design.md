# Terracotta Study 主题皮肤设计

日期：2026-04-29  
状态：设计已确认，等待用户 review 后进入实施计划

## 背景

当前站点是 Hexo 7.3 + Stellar 1.33.1，已经建立了博客、知识库、项目、碎碎念、关于等页面，并通过 `_config.stellar.yml` 配置了左侧导航、左右侧栏、小组件和站点树。用户明确说明当前配置好用，本次需求是参考 `https://xaoxuu.com/` 与 `https://blog.zhilu.site/` 的主题设计，做一套自定义主题皮肤，而不是重构信息架构。

本设计采用轻量皮肤层方案：保留现有 Stellar 配置和主题源码，只在站点自有样式层调整视觉系统。

## 目标

为当前博客设计一套名为 `Terracotta Study` 的二次开发主题皮肤。视觉定位是“暖白纸张上的赛博书房”：保留 Stellar 的信息密度、侧栏结构和知识库能力，同时用更有个人辨识度的暖陶土色盘统一站点气质。

成功标准：

- 不改变当前导航、侧栏、wiki、文章和页面配置。
- 不直接修改 `themes/stellar` 源码。
- 使用站点自有 CSS 覆盖视觉层，便于后续升级 Stellar。
- 页面整体从默认 Stellar 视觉变为统一的暖白、陶土、深青绿书房风格。
- 文章阅读、菜单、卡片、标签、按钮、小组件、代码块都有一致的色彩规则。

## 非目标

本次不做深度主题分支，不重写 EJS layout，不新增复杂交互，不更改内容结构，不引入新的前端框架，也不把首页改成营销页或独立门户页。

## 参考方向

`xaoxuu.com` 的参考价值在于 Stellar 系主题的长期内容系统感：侧栏、wiki、文章、组件组合形成稳定的信息工作台。

`blog.zhilu.site` 的参考价值在于清晰的个人博客组织方式：文章、精选内容、分类和站点信息之间关系明确，页面读起来有秩序。

本主题不复制两者外观，而是吸收这两个方向：用 Stellar 的工作台结构承载内容，用更统一的色彩和排版建立个人站辨识度。

## 色彩系统

用户指定色盘：

- Terracotta Rust：`#AE5238`
- Mustard Yellow：`#D39932`
- Deep Teal：`#225D65`
- Olive Green：`#5C633E`
- Warm Cream：`#E3D8C6`
- White：`#FFFFFF`

使用规则：

- 页面背景使用 Warm Cream 的浅化纸张色，避免大面积纯白刺眼。
- 内容主体和重要卡片使用白色，形成干净阅读面。
- Terracotta Rust 作为主色，用于站点标题、当前导航、重点按钮、文章标题 hover 和关键分隔线。
- Mustard Yellow 作为小面积强调色，用于标签、徽章、引用块边线、提示块和活动状态点缀。
- Deep Teal 作为功能色，用于链接、目录激活、搜索高亮、知识库入口和部分交互状态。
- Olive Green 作为辅助色，用于稳定、笔记、统计、次级状态或小组件标题装饰。
- 正文文字使用接近炭黑的暖黑，不使用纯黑；弱文字使用暖灰，避免冷灰系统感过强。

## 视觉规则

整体风格应克制、温暖、清晰，不做大渐变、装饰光球或过度拟物纹理。背景可以有极轻微纸张层次，但不能影响阅读。

卡片保持 Stellar 的信息密度，圆角控制在小幅度范围，阴影低而柔，边框用暖灰或 Warm Cream 的深一阶颜色。视觉上像纸张层叠，而不是厚重玻璃卡片。

左侧栏保留当前结构，视觉上更像“书房索引”。logo 区域使用更温暖的标题和弱边界，当前菜单项用 Terracotta Rust 强调，菜单 hover 可以使用 Warm Cream 背景和 Deep Teal 文本。

右侧栏统计与技术信息继续保留。现有 `.site-info-card` 样式可继续使用，但视觉上应统一到新色盘：标签用暖灰或 Olive Green，数值用暖黑或 Deep Teal，分隔线用轻量暖灰虚线。

文章阅读区优先保证中文阅读舒适度。段落行高略高于默认，标题层级清楚，二级标题可用 Terracotta Rust 或带短分隔线的方式突出，链接使用 Deep Teal，引用块使用 Mustard Yellow 边线和 Warm Cream 背景。

代码块保留技术感，但避免与暖色主题割裂。可选浅暖灰代码块或深青灰代码块；若使用深色代码块，应以 Deep Teal 的低饱和深色为底，不使用高对比纯黑。

## 组件规则

导航：

- 当前项：Terracotta Rust 文本或左侧标识。
- hover：Warm Cream 背景，Deep Teal 文本。
- 图标：默认继承文字色，避免多色菜单造成杂乱。

链接：

- 默认 Deep Teal。
- hover 转 Terracotta Rust。
- 正文链接保留可识别下划线或底色，不只依赖颜色变化。

标签和徽章：

- 默认使用 Warm Cream 背景和 Terracotta Rust 文本。
- 强调标签使用 Mustard Yellow，但只小面积出现。
- 技术/知识库类标签可使用 Deep Teal。

按钮：

- 主按钮使用 Terracotta Rust 背景和白色文字。
- 次按钮使用白色背景、Warm Cream 边框和 Deep Teal 文本。
- hover 状态只做轻微色彩和边框变化，避免跳动。

小组件：

- widget 标题使用暖黑文字，辅以 Olive Green 或 Terracotta Rust 的小色条。
- widget body 使用白色或浅 Warm Cream 背景。
- 统计类数值保持右对齐和省略策略，避免窄侧栏溢出。

文章列表：

- 标题 hover 使用 Terracotta Rust。
- 元信息使用暖灰。
- 分类/标签用统一 badge 规则。
- 卡片之间通过留白和浅边框分隔，不用重阴影。

## 实施边界

首选修改：

- `source/css/_custom.styl`

可保留或同步调整：

- `source/css/site-info.css`
- `_config.stellar.yml` 中现有 `inject.head` 引入方式

禁止修改：

- `themes/stellar` 源码
- 当前导航结构
- 当前 `site_tree` 布局
- 当前 wiki、文章、项目、碎碎念页面结构

如需新增 CSS 变量，应集中在自定义样式文件顶部，使用语义化命名，例如 `--ts-rust`、`--ts-mustard`、`--ts-teal`、`--ts-olive`、`--ts-cream`。

## 测试与验收

实施后需要验证：

- `npm run build` 成功。
- 生成后的首页、文章页、wiki 页、项目页和关于页都能加载自定义样式。
- 左侧导航当前项、hover、图标颜色一致。
- 右侧统计卡在窄侧栏下不溢出。
- 正文链接、标题、引用块、代码块符合新色盘。
- 深浅背景下文字对比足够，中文正文可读。
- 浏览器控制台没有因为 CSS 注入路径导致的 404。

## 后续扩展

如果后续需要更明显的主题差异，可以在不破坏当前配置的前提下继续增加：

- 首页欢迎区的轻量视觉强化。
- 文章列表的精选标识。
- 项目页的统一项目卡片样式。
- 深色模式下的 Terracotta Study 变体。

这些扩展应作为后续小步任务处理，避免一次性进入深度主题分支。
